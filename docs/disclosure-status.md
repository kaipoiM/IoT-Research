# Coordinated Disclosure Status

This project follows a coordinated vulnerability disclosure (CVD) process for all findings against commercial devices. Full technical detail for unpatched findings is withheld from this public repository until the applicable disclosure window closes or a vendor fix ships.

This page is a public-safe status tracker. It shows that a disciplined process exists and where each vendor stands, without reproducing embargoed detail.

## Process

1. Confirm findings against researcher-owned units on a controlled network.
2. Open a coordinated channel with the vendor; agree on a point of contact.
3. Send a full technical report. **This date starts a 90-day window**, extendable by mutual agreement if a fix needs more time.
4. Withhold public detail until the window closes or a fix ships, whichever comes first.
5. Release detail per device as each window closes; credit the vendor's handling.
